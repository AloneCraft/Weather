空模様(以下「本アプリ」)は、利用者の個人情報をできるだけ扱わないように作られています。本アプリは公開者のサーバーを経由せず、各気象機関から直接データを取得します。公開者は利用者を特定できるデータを受け取りません(広告の表示回数・収益などの集計値を除く)。

本アプリは無料で、広告(Google AdMob)を表示します。広告に関するデータの扱いは「2. 通信先」と「3. 広告」を参照してください。

## 1. 位置情報

- 「現在地」を使うと、端末の位置情報を予報の取得のためだけに使います。位置情報の許可は「アプリの使用中のみ」で、バックグラウンドでの位置情報は使いません。
- 地点の判定(どの機関の予報を使うか、気象庁の予報区域など)は端末内で行い、位置を外部に送りません。
- 予報を取得するとき、米国国立気象局(NWS)と MET Norway には、座標を小数第 2 位(約 1 km)に丸めて送ります。気象庁には座標を送らず、予報区域・観測所の番号だけを使います。
- 本アプリは端末の位置情報を広告に渡しません(広告の配信事業者は IP アドレスからおおよその地域を推定することがあります)。

## 2. 通信先

本アプリは、次の気象機関の公開 API に直接接続します。各機関には、通信の性質上、利用者の IP アドレスと本アプリの名称・版(User-Agent)が伝わります。各機関での扱いは、それぞれのプライバシーポリシーに従います。

| 機関 | 接続先 | 送る情報 |
|---|---|---|
| 気象庁 | www.jma.go.jp | 予報区域・観測所の番号 |
| 米国国立気象局(NWS) | api.weather.gov | 丸めた座標、観測所の番号 |
| MET Norway | api.met.no | 丸めた座標 |
| Google(AdMob・同意管理) | Google の広告配信のサーバー | 広告 ID(Android の広告 ID、iOS では許可した場合のみ IDFA)、端末とアプリの情報(機種・OS・言語など)、広告の表示・タップの記録、同意の状態 |
| Apple / Google(課金) | App Store / Google Play | 「広告を消す」を購入・復元するときの購入の情報(各ストアのアカウントで処理されます) |

アクセス解析・クラッシュ報告のサービスは使いません。本アプリへのアカウントの登録もありません。

## 3. 広告

- 広告は地図と地点の詳細の画面の下部にだけ表示します。「広告を消す」を購入すると表示しなくなります。
- 広告の配信には Google AdMob を使います。Google によるデータの扱いは、Google のプライバシーポリシー(https://policies.google.com/privacy)と、広告におけるデータの使用(https://policies.google.com/technologies/ads)に従います。
- 利用者の興味に合わせた広告(パーソナライズド広告)は、利用者が同意した場合にだけ表示します。
  - 欧州経済領域(EEA)・英国など同意が必要な地域では、初回に同意の画面を表示します。同意は「設定」の「広告のプライバシー設定」からいつでも変更できます。
  - iOS では、アプリをまたいだトラッキングの許可(App Tracking Transparency)を求めます。許可しない場合、IDFA は使われません。許可は端末の「設定」でいつでも変更できます。
  - Android では、端末の設定で広告 ID を削除・リセットできます。
- 同意しない場合や許可しない場合も広告は表示されますが、利用者の興味に合わせない広告になります。
- 購入の情報は Apple / Google が処理し、公開者は支払いの情報を受け取りません。本アプリは購入済みかどうかだけを端末に記録します。

## 4. 端末内に保存するデータ

| データ | 用途 | 削除の方法 |
|---|---|---|
| お気に入りの地点 | 地点の一覧 | 「地点の管理」画面で削除、またはアプリの削除 |
| 観測履歴 | 観測所の過去の観測値の表示(保持期間は設定で選択) | 「設定」の「観測履歴をすべて削除」、またはアプリの削除 |
| 設定 | 単位・描画品質・通知など | アプリの削除 |
| 取得したデータの一時保存 | 通信量の削減とオフライン時の表示 | 自動(容量・期限で削除)、またはアプリの削除 |
| ウィジェットの表示内容・通知済みの警報の記録 | ウィジェットの表示、同じ警報の再通知の防止 | アプリの削除 |
| 「広告を消す」の購入済みの記録 | 起動直後・オフライン時にも広告を出さない(起動時にストアで確認し直します) | アプリの削除(購入はストアに残り、「購入を復元」で戻せます) |
| 広告の同意の状態 | 同意の画面を毎回出さない(Google の同意管理の仕組みが保存します) | 「広告のプライバシー設定」で変更、またはアプリの削除 |

Android の自動バックアップ・iOS のバックアップが有効な場合、お気に入りと観測履歴は OS の機能で利用者のアカウントにバックアップされることがあります。本アプリの提供者はその内容を受け取りません。

## 5. 通知とバックグラウンドでの取得

- 「警報の通知」を有効にした場合、またはウィジェットを置いた場合に限り、本アプリはバックグラウンドで気象庁・NWS からお気に入りの地点の警報と予報を取得します(実行の頻度は OS が決めます)。
- MET Norway の利用規約により、MET Norway の地点についてはアプリを使用していないときに取得しません。
- 通知は端末内で作成し、外部のプッシュ通知サービスは使いません。

## 6. 子どものプライバシー

本アプリは子ども向けに作られたものではありません。本アプリ自体は個人を特定できる情報を収集しませんが、広告の配信のため上記のデータが Google に送られます。
